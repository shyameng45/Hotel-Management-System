# Hotel Management System

A project-based learning (PBL) submission for a Hotel Management System.

## Overview

This repository contains the project report (`Hotel_Management_PBL.pdf`) documenting the design and implementation of a Hotel Management System.

## Contents

| File | Description |
|------|-------------|
| `Hotel_Management_PBL.pdf` | Full project report including system design, features, and implementation details |

## Features (as described in the project report)

- Room booking and reservation management
- Guest check-in and check-out
- Billing and invoicing
- Staff and inventory management

## How to View

Open `Hotel_Management_PBL.pdf` with any PDF viewer to read the full project report.
